# Lab Flutter

A Flutter project developed as part of a practical lab for learning and practicing Flutter application development.

## 📱 About the Project

This project is a starting point for building a cross-platform mobile application using **Flutter** and **Dart**.

The purpose of this project is to practice the fundamental concepts of Flutter development, including:

* Building user interfaces with Flutter widgets
* Managing application layouts and screen structure
* Handling user interactions and events
* Working with Dart programming language
* Navigating between different screens
* Managing application state
* Running and testing Flutter applications on different platforms

## 🛠️ Technologies

* **Flutter** — UI framework for building cross-platform applications
* **Dart** — Programming language used by Flutter
* **Android Studio / IntelliJ IDEA / VS Code** — Development environment

## 📂 Project Structure

The main project structure follows the standard Flutter project layout:

```text
lab_flutter/
├── android/          # Android-specific configuration
├── ios/              # iOS-specific configuration
├── lib/              # Main application source code
│   └── main.dart     # Application entry point
├── test/              # Unit and widget tests
├── pubspec.yaml      # Project dependencies and configuration
└── README.md         # Project documentation
```

The `lib/` directory contains the main source code of the application, while `main.dart` serves as the entry point of the Flutter application.

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have installed:

* [Flutter SDK](https://docs.flutter.dev/get-started/install)
* [Dart SDK](https://dart.dev/get-dart) — included with Flutter
* Android Studio or Visual Studio Code
* An Android emulator, iOS simulator, or a physical device

You can verify your Flutter installation by running:

```bash
flutter doctor
```

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd lab_flutter
```

Install the required dependencies:

```bash
flutter pub get
```

### Running the Application

Start an emulator or connect a physical device, then run:

```bash
flutter run
```

Alternatively, the project can be launched directly from Android Studio or Visual Studio Code.

## 🧪 Testing

To run the project's tests, use:

```bash
flutter test
```

Flutter also provides tools for analyzing the source code:

```bash
flutter analyze
```
